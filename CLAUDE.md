# Claude Instructions

This repository is used for practicing AI-assisted frontend development during the FlyRank internship.

## Coding Guidelines

- Write clean and readable code.
- Use meaningful commit messages.
- Follow frontend best practices.
- Ask AI for suggestions before implementing features.
## Project Rules Learned

1. Always validate user input before submission.
2. Disable the submit button until all required fields are valid.
3. Display inline validation errors instead of relying on browser alerts.
4. Use semantic HTML and accessibility attributes wherever possible.
5. Test AI-generated code before accepting it.
